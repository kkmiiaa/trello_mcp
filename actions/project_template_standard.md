# 🎯 TrelloActions GPT 標準プロジェクトテンプレート定義

最終更新日：2026-01-11  
 作成者：Kamiura  
 対象：TrelloActions GPT（内部知識参照用）

---

## 🧩 プロジェクトボード標準構成（最新版）

### 🗂 リスト構成

| リスト名      | 目的・役割                                                                                                                                                                                                     |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 🗃️ Backlog    | 未着手・検討中のアイデアやタスクを一時保管する。まだやるか決まっていないものをここに置く。                                                                                                                     |
| ✅ TODO       | 取り組む予定が確定しているタスク。短期的に実行するもの。                                                                                                                                                       |
| 🚧 InProgress | 現在進行中のタスク。作業中のカードをここに集約。                                                                                                                                                               |
| 🏁 Done       | 完了済みタスク。定期的にアーカイブしても良い。                                                                                                                                                                 |
| 🚀 Milestone  | プロジェクト全体の進行段階（例：α版・β版・RC版・v1.0など）を定義する。各カードは「フェーズの説明」と「完了条件」を含む。カード名・色ラベルで段階を識別し、同じラベルをタスクカードにも付与することで紐づける。 |
| 🧠 Info       | プロジェクト関連の資料・仕様・参考リンク・ドキュメントなどを整理する。知識・メモ置き場。                                                                                                                       |

---

## 🚀 Milestoneリストの詳細運用ルール

| 項目            | 内容                                                                                                                                 |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 役割            | プロジェクトの進行フェーズを定義し、全体像を把握する。                                                                               |
| カード構成例    | α版 → β版 → RC版 → v1.0.0 の順番に上から並べる。                                                                                     |
| カード内容      | 名前＝マイルストーン名、説明＝そのフェーズの目標・完了条件、期限＝想定リリース日。                                                   |
| ラベル運用      | 各マイルストーンに対応したラベルを作成し、関連タスクに同ラベルを付与。これにより、タスクがどのマイルストーンに属するかが明確になる。 |
| #ボードとの関係 | Milestone情報は #ボードの「進行状況」リストに集約し、全体進行を俯瞰。                                                                |

---

## 🧭 #ボード（ハブ）の目的・運用方針

| 項目       | 内容                                                                                                                                                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 目的       | 全プロジェクトを横断して「今日」「今週」「進行状況」「目標」を一元管理するハブ。                                                                                                                                            |
| リスト構成 | 今日のタスク / 今週のタスク / プロジェクト進行状況 / 行動ルール / その他のボード（プロジェクト概要） / 目標・OKR / インボックス                                                                                             |
| 運用ルール | - 毎日：「今日のタスク」リストを整理、完了タスクをアーカイブ<br>- 週1回：「今週のタスク」を見直し、翌週へ反映<br>- 各プロジェクトの進捗を「進行状況」リストで更新<br>- 新しいプロジェクトやアイデアは絵文字ボードから昇格。 |

### リストの役割

| リスト名                           | 目的・役割                                                                                  |
| ---------------------------------- | ------------------------------------------------------------------------------------------- |
| 今日のタスク                       | 今日やることに絞って可視化し、完了したらアーカイブする。                                    |
| 今週のタスク                       | 今週中に進めるタスクを管理し、週次で見直す。                                                |
| プロジェクト進行状況               | 各プロジェクトの進捗を「未着手 / 進行中 / 運用中 / 完了」の区分で短い要約カードにまとめる。 |
| 行動ルール                         | 睡眠時間など生活・仕事の必須ルールを明文化し、日々確認できるようにする。                    |
| その他のボード（プロジェクト概要） | プロジェクト以外のボード情報や概要の整理を行う。                                            |
| 目標・OKR                          | 期間目標や指標を集約し、タスクの優先度を判断する軸にする。                                  |
| インボックス                       | 未整理のタスクやアイデアを一時保管し、定期的に振り分ける。                                  |

---

## ☁️💡⚡️ 絵文字ボード（アイデアボード）

| 項目       | 内容                                                                                           |
| ---------- | ---------------------------------------------------------------------------------------------- |
| 役割       | 自由な発想・着想・メモの置き場。構想段階のアイデアをためる。                                   |
| 運用ルール | - 思いついたら自由に追加<br>- 具体化されたものは #ボードに昇格し、必要に応じてプロジェクト化。 |

---

## 🔗 全体構造

☁️💡⚡️（アイデアボード）  
 　↓ アイデア採用  
 #（ハブボード）  
 　↓ プロジェクト起動  
 各プロジェクトボード  
 ├─ Backlog  
 ├─ TODO  
 ├─ InProgress  
 ├─ Done  
 ├─ Milestone ← 進行フェーズ定義・タスク紐づけ  
 └─ Info ← 資料・メモ・仕様集約

## 📘 GPT動作ポリシー（参照用）

| 状況                 | GPTの動作方針                                                   |
| -------------------- | --------------------------------------------------------------- |
| 新規プロジェクト作成 | 標準構成（Backlog〜Info）を自動生成                             |
| 新マイルストーン追加 | Milestoneリストにカード作成＋ラベル発行                         |
| タスク作成           | Backlog〜InProgress内に作成し、対応マイルストーンのラベルを付与 |
| 進捗更新             | #ボード「進行状況」リストにマイルストーンごとの進捗を要約       |
| 完了フェーズ         | Milestoneカードを完了状態にし、#ボードへ反映                    |
