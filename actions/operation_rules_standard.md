# 🧭 TrelloActions 運用ルール標準定義

最終更新日：2026-01-14  
作成者：Kamiura  
対象：#ボードおよび関連プロジェクト

---

## 🎯 基本方針

- 各プロジェクトの進行状況は **#ボード（ハブ）** を唯一の参照元とする。
- 新規ボードは原則作成しない。既存構造（☁️💡⚡️ → # → 各プロジェクト）を維持。
- GPTは#ボードを最優先参照し、進捗・整理・報告を行う。

---

## 🔁 同期・更新ルール

（#ボードとプロジェクトの整合性維持）

| 項目     | 内容                                                            |
| -------- | --------------------------------------------------------------- |
| GPT同期  | 構造変更やマイルストーン更新時は「GPTに再同期」と明示して指示。 |
| 手動更新 | 各プロジェクトのInProgress/Done更新時に#ボードも確認。          |

---

## 🧹 整理・アーカイブルール

（ボードを常に最新状態に保つ）

| 項目 | 内容                                             |
| ---- | ------------------------------------------------ |
| 毎日 | 「今日のタスク」完了分をアーカイブ。             |
| 毎週 | 「今週のタスク」「進行中プロジェクト」を見直し。 |
| 毎月 | 完了プロジェクトを整理・棚卸し。                 |

---

## 🏷 ラベル・マイルストーン運用

| 項目     | 内容                                                            |
| -------- | --------------------------------------------------------------- |
| 紐づけ   | 各プロジェクトのMilestoneカードと関連タスクに同一ラベルを付与。 |
| 色ルール | α＝赤／β＝オレンジ／RC＝黄／v1.0＝緑 など統一管理。             |

---

## 🔒 権限・操作範囲

| 項目        | 内容                                                                    |
| ----------- | ----------------------------------------------------------------------- |
| ボード権限  | 管理者（Kamiura）が作成・削除・構造変更を行う。                         |
| GPT操作範囲 | GPTは既存構造内のカード作成・更新・同期のみ実行。新規ボードは作らない。 |

| ------------ | ---------- | ------------------------------------------------ |
| デイリー     | 朝         | 「今日のタスク」を確認・更新。                   |
| ウィークリー | 週初め     | 「今週のタスク」「進行中プロジェクト」を見直す。 |
| マンスリー   | 月初       | 「運用ルール」カードを読み直し、改善を検討。     |

## ✅ 週次タスク整理の厳密手順（#ボードの「今週のタスク」更新）

この手順は**必ず順番通り**に実行する。省略・入れ替えは禁止。

1. **前提確認**: 進行中プロジェクトボード内のタスクが現状に合っている前提で作業する。  
2. **#ボード確認**: `#ボード` の「進行中プロジェクト」リストを確認する。  
3. **各プロジェクト確認**: 対象プロジェクトボードの `TODO` と `InProgress` を確認する。  
4. **期限フィルタ**: 期限が設定されているカードのみを対象にし、**今日から1週間以内**に期限があるカードを抽出する。  
5. **#ボード反映**: 抽出したカードを `#ボード` の「今週のタスク」リストへ**コピー**して記載する。  

**禁止事項**
- 期限未設定カードを「今週のタスク」に入れない。  
- `TODO` / `InProgress` 以外のリストから拾わない。  
- 期限条件（今日から1週間以内）を満たさないカードを入れない。  
- 元カードを移動しない（必ずコピーする）。

## 🧩 運用設計思想

> #ボードを「脳幹」とし、すべての情報・進捗・意志決定を一元化する。  
> GPTはその補助思考として、整理・同期・視覚化を担う。
